# DSA Question Checklist — Start to Finish

## How to Use

- Start from Phase 1 and move sequentially.
- Mark every question with one of these states:
  - `[ ]` Not started
  - `[~]` Tried but not solved fully
  - `[x]` Solved cleanly
  - `[r]` Needs revision
- focus more on explanation, edge cases, complexity, and clean code than memorizing answers.
